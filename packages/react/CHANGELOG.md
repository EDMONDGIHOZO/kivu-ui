# Changelog

All notable changes to `@kivu-ui/react` will be documented here.

The project follows [Semantic Versioning](https://semver.org/). While the package is in `0.x`, minor releases may include public API refinements.

## 0.1.0 - Unreleased

### Added

- Initial React component library with TypeScript declarations and ESM/CommonJS entry points.
- Themeable CSS variables, dark mode and optional Tailwind CSS v4 token integration.
- Form, navigation, overlay, feedback, data-display, date-selection and layout components.
- Lightweight chart color helpers and sparkline component.
- React 18 and React 19 peer support.
